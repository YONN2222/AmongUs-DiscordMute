title: Setup panel
description: Configure the bot for your Discord server with /setup, and give the bot the permissions it needs.
---

Every server has its own settings. You change them with the `/setup` command, not in a file.

::note
Update the plugin and the bot together. A 2.x plugin still works with a 3.0 bot, without the player list, deaths and match results that several of the features below use.
::

## Open the panel

Run `/setup` in any channel. Only members with the **Manage Server** permission can use it. The panel is private: only you see it, in your Discord language. It has four pages, which you switch with the menu at the top.

Every change is saved immediately. If you set a [log channel](/server-setup/game-features#log-channel), it shows who changed what.

When you pick a channel, the bot checks that it can post there and refuses the channel with a message if it cannot. The old value stays. Clear the selection to turn a feature off again.

## General

| Setting | Default | Meaning |
|---------|---------|---------|
| Language | English | The language of all public bot messages (English or German). Private replies use the language of the person who clicks. |
| Log channel | off | Where the bot writes its [server log](/server-setup/game-features#log-channel). |

The page also shows whether the Among Us plugin is connected right now.

On the hosted bot, this page also holds the plugin secret: you create it once and can generate a new one later. See [hosted setup](/getting-started/hosted-setup).

## Links

| Setting | Default | Meaning |
|---------|---------|---------|
| Link overview channel | off | A message that lists every linked player and updates itself. See [Link overview](/server-setup/game-features#link-overview). |
| Show pending links | off | Also list members who started `/link self` and are still waiting. |
| Relink returning players | on | Keeps links working when a player renames their Among Us account. See [Automatic relink](/server-setup/game-features#automatic-relink). |

## Voice

| Setting | Default | Meaning |
|---------|---------|---------|
| Living players during tasks | Muted | What happens to players who are alive while a round runs: Free, Muted or Deafened. |
| Dead players during tasks | Muted | The same for dead players during a round. |
| Living players in meetings | Free | The same for living players in a meeting. |
| Dead players in meetings | Muted | The same for dead players in a meeting. |
| Ghost chat | off | Dead players talk during tasks while the living are deafened. Read the [warning](/server-setup/game-features#ghost-chat) first. |
| Voice members who are not in the game | Leave alone | Members in the voice channel without a linked player: Leave alone, Mute, or Treat as dead. |
| Fallback voice channels | none | Hosted bot only. Channels the bot mutes when it cannot tell which channel the host is in. |
| Delays | 0 s each | Waits before a change is applied: game start, meeting start, meeting end, back to the lobby. Each value is 0 to 5 seconds. You can type `1.5` or `1,5`. |

In the lobby, everybody is unmuted and undeafened.

## Game

| Setting | Default | Meaning |
|---------|---------|---------|
| Status message channel | off | A live message about the running game. See [Status message](/server-setup/game-features#status-message). |
| Lobby code in the status message | Spoiler | Always show, Spoiler (hidden until clicked) or Hide. |
| Match summary channel | off | Where the result of every game is posted. See [Match summary](/server-setup/game-features#match-summary). |
| Delete the summary after | Never | Never, or 5 min, 15 min, 30 min, 1 h, 4 h or 24 h. |
| Nickname sync | off | Shows the Among Us name as the server nickname during a game. See [Nickname sync](/server-setup/game-features#nickname-sync). |

## Bot permissions

Give the bot these permissions. Without them the matching feature silently does nothing, or reports the problem in the log channel.

| Permission | Needed for |
|------------|------------|
| Mute Members | Muting players. |
| Deafen Members | Deafening players (the Deafened rule and ghost chat). |
| Manage Nicknames | Nickname sync. |
| View Channel | Every channel you pick in the panel. |
| Send Messages | Every channel you pick in the panel: log, overview, status and summary. |
| Manage Messages | The link overview and status channels. The panel refuses these two channels when the bot does not have it. |

::warning
Discord only lets a bot change members whose highest role is **below** the bot's own role. Move the bot role above the roles of your players, otherwise muting and nicknames are refused. The log channel reports this.
::
