---
title: Plugin configuration
description: Every setting of the DiscordMute plugin in Among Us.
---

The plugin creates its `config.json` the first time you start Among Us. You find it in `BepInEx/DiscordMute` inside your Among Us folder.

::warning
In a folder path, write every backslash twice (`C:\\Path`) or use forward slashes (`C:/Path`). A single backslash breaks the file and the plugin falls back to its defaults.
::

## Settings

| Setting | Default | Meaning |
|---------|---------|---------|
| `mode` | not set | Set to `hosted` to use the [hosted bot](/getting-started/hosted-setup), which is available now. Leave it out when you run the bot yourself. In hosted mode `ip`, `botPort` and `exe` are ignored. |
| `ip` | `localhost` | The address of the PC that runs the bot. |
| `botPort` | `7264` | The port of the bot. It must match the bot. |
| `secret` | `change-me` | The plugin secret of your server. Create it with `/setup` on the **General** page, for your own bot and for the hosted bot alike. |
| `exe` | empty | The full path to `start.bat` in the `DiscordBot` folder. The plugin starts the bot from there. |
| `bridgeLogsToBotConsole` | `false` | Show all plugin and BepInEx messages in the bot window. Warnings and errors from the plugin always show. Ignored in hosted mode, where no plugin logs are sent. |
| `disableUpdateCheck` | `false` | Set to `true` to turn off the [update check](/privacy/update-check). The line is only in the file if you add it. |

## Example

```json
{
  "ip": "localhost",
  "botPort": 7264,
  "secret": "dmh_your-secret",
  "exe": "C:\\Path\\To\\DiscordBot\\start.bat"
}
```

For the hosted bot you only need two keys:

```json
{
  "mode": "hosted",
  "secret": "dmh_your-secret"
}
```
