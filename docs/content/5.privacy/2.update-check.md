---
title: Update check
description: How DiscordMute tells you that a newer version is available and how to turn it off.
---

The bot and the plugin check whether a newer DiscordMute release exists. Nothing about you is sent. The check is a normal request to GitHub, so GitHub sees it like any other web request.

## When you are told

- **Bot:** a notice appears in the bot window at start and then once a day.
- **Plugin:** it checks once each time you start the game and become the lobby host. A single notice then appears in the lobby chat.

When you see a notice, update the plugin and the bot together.

## Turn it off

Add this line to the bot `config.json`:

```json
"disableUpdateCheck": true
```

The plugin has its own switch. Add the same line to the plugin `config.json` to turn its check off too. See [bot configuration](/configuration/bot-config) and [plugin configuration](/configuration/plugin-config).
