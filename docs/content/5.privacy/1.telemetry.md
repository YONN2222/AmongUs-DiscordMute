---
title: Anonymous telemetry
description: What the DiscordMute bot shares about its usage, what it never shares and how to turn it off.
---

DiscordMute sends a small anonymous usage report by default. Please leave it on. These few numbers are the only way to see how DiscordMute is really used, which versions are still out there and where it needs to get better. It counts things, it does not track people.

## What is sent

A report goes out every 5 minutes to `mute.yonn2222.com`. It contains:

- A random instance id, created once on the first start. It is not based on anything about you or your PC.
- A random id for each report.
- Whether your bot is self-hosted or hosted.
- The bot version, and how many connected plugins use each plugin version and each Among Us version.
- Counts: linked users, running games, servers the bot is in and connected plugins.
- Counts since the last report: games muted, mutes, unmutes, times Discord slowed the bot down, and lobbies, game starts, meeting starts and meeting ends.
- How fast muting is: the average time in milliseconds.
- For each optional feature, how many servers use it. Only a number, never which servers.

## What is never sent

Discord IDs, server or channel names, player names, secrets, or scrambled versions of any of these.

Like any web request, the connection reaches the server from your IP address. It is only used to limit how often one sender can report and is not stored with the report.

## When it is active

Telemetry runs in the bot program (`bot.exe`) you download from a release. If you run the bot from the source code, it stays off.

## Turn it off

Open the bot `config.json` and add this line:

```json
"disableTelemetry": true
```

The line is not in `config.example.json` on purpose, you add it yourself. See [bot configuration](/configuration/bot-config) for how to edit the file.
