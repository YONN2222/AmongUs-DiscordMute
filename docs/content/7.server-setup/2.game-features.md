---
title: Game features
description: What the log channel, link overview, status message, match summary, voice rules, ghost chat, nickname sync and automatic relink do.
---

Turn these on with [`/setup`](/server-setup/setup-panel). Features that post messages stay off until you pick a channel for them.

## Log channel

The bot writes a short log into one channel: when the plugin connects or disconnects, when a game starts and ends (with the winners and who died), who linked or unlinked an account, and every settings change with the name of the admin. Several lines are bundled into one message, so a busy game does not flood the channel.

Problems with muting are reported here too, for example a missing **Mute Members** or **Deafen Members** permission or a bot role that sits too low. Each kind of problem is reported at most once every 10 minutes. If the bot cannot post in the channel, it pauses the log for 10 minutes. Changing any setting in `/setup` resumes it right away.

## Link overview

A message in the channel you pick lists every linked Discord member and their Among Us name. It has buttons for **Link** and **Unlink**, so players can link without typing a command, and it updates itself a few seconds after every change. If the server has more than 20 links, **Show more** opens a private, paged list.

Admins get extra controls in that private list only: unlink a member, or force a link by Discord user and Among Us name. The public message never shows admin buttons.

If someone deletes the message, the bot posts a new one on the next change. Turn on **Show pending links** to also list members who started linking and have not finished.

## Status message

While a game runs, the bot keeps one message up to date in the channel you pick: the phase (lobby, round or meeting), the host, the lobby code and the players. The lobby code is hidden as a spoiler by default. Deaths only appear at the next meeting, so the message does not give away who died. The bot deletes the message when the host leaves or the plugin disconnects.

## Match summary

After every game the bot posts the result: why the game ended, the winners, how long it took and every player. You can have it deleted automatically after a time you choose, or keep it forever.

## Voice rules

For each phase you decide what happens to living and dead players: **Free**, **Muted** or **Deafened**. Defaults are muted during tasks, living players free in meetings, and dead players muted everywhere. Everybody is free in the lobby.

You can also delay each change by up to 5 seconds, for example so that a meeting does not start the instant the body is reported. A death is never delayed.

Members in the voice channel who are not linked to a player can be left alone, muted, or treated like dead players.

## Ghost chat

::warning
Ghost chat can leak information. It replaces the task rules: dead players talk freely while the living are **deafened**. If a deafen fails, for example because the **Deafen Members** permission is missing or the bot role is too low, the living hear the dead. Check the log channel and test it before you rely on it.
::

Meeting rules are not changed by ghost chat.

## Nickname sync

With nickname sync on, a linked player who is in the game's voice channel gets their Among Us name as server nickname when the game starts. The bot restores the original nickname when the game ends, and after a crash or restart. It never overwrites a nickname the member changed in the meantime. This needs **Manage Nicknames**. Nicknames are cut to 32 characters.

## Automatic relink

When a player changes their Among Us name, the link would normally break. With automatic relink on, the bot learns each player's friend code from the game and renames the link when the same account shows up under a new name. The change is written to the log channel. Turn it off if you prefer to relink by hand with `/link self`.

## Safety after a crash

The bot keeps a record of every mute and nickname it applied. After a crash or restart it lifts them again. It checks every minute for leftovers when no game is running, and lifts a leftover mute as soon as the member rejoins voice. It only lifts what it set itself.
