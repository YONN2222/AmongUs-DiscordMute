## The bot says the secret was rejected

The `secret` in the plugin and in the bot must be exactly the same. The most common cause is a plugin `config.json` that is broken, usually because of a single backslash in the `exe` path. The plugin then silently uses its defaults, including the secret `change-me`. Write `\\` or `/` in paths and search `BepInEx/LogOutput.log` for `Failed to read plugin config`.

## The plugin says the server is blocked

The operator of the hosted bot has blocked your Discord server or the host. The plugin stays disconnected until you restart Among Us. Contact the operator if you think this is a mistake, or [run your own bot](/getting-started/self-host-setup).

## The plugin says the bot left this server

The hosted bot is no longer in your Discord server: someone removed it, or the operator removed it without blocking it. Add the bot again and restart Among Us. Within 7 days the secret, settings and links are kept. After that they are deleted: run `/setup` to create a new secret, put it into the plugin `config.json` and link again.

## Players stay muted after the bot was removed

Removing the bot during a game can leave members server-muted. Unmute them in Discord, or add the bot back, which lifts the mutes.

## Too many games on this server

The bot limits how many games can run on one Discord server at the same time. The plugin retries every 60 seconds and connects when a game ends.

## I lost my secret

The secret is shown only once. Run `/setup`, open the **General** page and press **Generate new secret**. Put the new secret into the plugin `config.json`. The old one stops working.

## The bot says the plugin is outdated

The bot refuses plugins older than 3.0. Update the plugin and the bot together. A 3.x bot refuses 2.x plugins as outdated, and a 3.x plugin cannot connect to a 2.x bot.

## Nobody gets muted

- The lobby host must be linked (`/link self`) and sit in a Discord voice channel. DiscordMute mutes the channel the host is in.
- You must host an online or local lobby. Freeplay does nothing.
- If the bot cannot tell which channel the host is in, it uses the channels in `channelIds`.
- Run `/testconnection` to check that the bot reaches the plugin.

## Players stay muted after a crash

On the next start the bot unmutes the players it muted itself. It leaves mutes that someone else applied alone. If someone was muted by hand, unmute them in Discord.

## I see an update notice

A newer release exists on GitHub. Update the plugin and the bot together. See [update check](/privacy/update-check).

## How do I turn off telemetry or the update check?

Add `"disableTelemetry": true` and `"disableUpdateCheck": true` to the bot `config.json`. For the plugin, add `"disableUpdateCheck": true` to its `config.json`. See [what telemetry sends](/privacy/telemetry).

## Why does my Windows path break the config?

The `\` character has a special meaning in these files. Write `"C:\\Path\\To\\start.bat"` or `"C:/Path/To/start.bat"`.

## Is itch.io supported?

No. The itch.io version is 32-bit. Steam, Epic Games and Microsoft Store versions are 64-bit and use the 64-bit BepInEx build.
