---

::note
Hosted mode is not available yet.
::

The planned flow: you invite the hosted DiscordMute bot to your Discord server, run `/setup` there to get a server secret, and put that secret into the plugin `config.json` with `mode` set to `hosted`. You then run no bot yourself. Until then, use the [self-host setup](/getting-started/self-host-setup).
