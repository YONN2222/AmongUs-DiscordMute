title: Hosted setup
description: Use the hosted DiscordMute bot. You run no bot yourself, you only add it to your server and set up the plugin.

With the hosted bot you run nothing on your PC except Among Us. You add the bot to your Discord server, create a secret and paste it into the plugin.

::note
The [website](https://mute.yonn2222.com) shows whether the hosted bot is open. To run your own bot, use the [self-host setup](/getting-started/self-host-setup).
::

## Steps

1. Add the hosted bot to your Discord server with the invite button on the [website](https://mute.yonn2222.com).
2. Install BepInEx and `DiscordMute.dll` as described in the [self-host setup](/getting-started/self-host-setup). Skip the bot part.
3. In Discord, run `/setup` and open the **General** page. You need the **Manage Server** permission.
4. Press **Create secret** and copy the secret. It starts with `dmh_` and is shown only once.
5. Start Among Us once, then open `config.json` in `BepInEx/DiscordMute` and set:

```json
{
  "mode": "hosted",
  "secret": "dmh_your-secret"
}
```

6. Host a lobby, join a Discord voice channel and run `/link self`, as in the self-host setup.

The plugin already knows the address of the hosted bot. You do not enter it.

## Good to know

- **Generate new secret** replaces the secret. The old one stops working and games that use it are disconnected.
- You can run several games on one server. Each game mutes the voice channel its host is in.
- If the bot cannot tell which channel the host is in, it uses the fallback voice channels from the **Voice** page of `/setup`.
- Removing the bot from the server deletes the server's secret, settings and links 7 days later. Add the bot back within 7 days and everything stays as it was. The operator can delete the data earlier on request.
- A server or host the operator has blocked cannot use the bot. The plugin log says so.

All other settings work as described in the [setup panel](/server-setup/setup-panel).
