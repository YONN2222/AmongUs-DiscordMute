The hosted bot is available now. You run nothing on your PC except Among Us: add the bot to your Discord server, create a secret with `/setup` and paste it into the plugin.

::note
Prefer your own bot? Use the [self-host setup](/getting-started/self-host-setup). Setup works the same way there: you create the secret with `/setup` too.
::

::tip
Only the lobby host needs the plugin. The other players play the normal game and only link their Discord account.
::

:::steps{level="2"}

## Add the bot to your server

Add the hosted bot to your Discord server with the invite button on the [website](https://mute.yonn2222.com).

## Create the secret

Run `/setup` in your server. You need the **Manage Server** permission. Language, log channel, voice rules and the rest are on the pages of the [setup panel](/server-setup/setup-panel).

1. Open the **General** page and press **Create secret**.
2. Copy the secret. It starts with `dmh_` and is shown only once.
3. Optional: on the **Voice** page, pick fallback voice channels for when the host is not in a voice channel.

## Install BepInEx

DiscordMute requires BepInEx.

- If you already use another Among Us mod that ships with BepInEx, you can usually skip this step.
- Otherwise, download the 64-bit BepInEx build. Among Us is a 64-bit game on Epic Games and the Microsoft Store, and the current Steam version is 64-bit too, so all of them use the same file:
  - Steam / Epic Games / Microsoft Store: [`BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.735+5fef357.zip`](https://builds.bepinex.dev/projects/bepinex_be/735/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.735%2B5fef357.zip)
- BepInEx 6.0.0-be.791 works as well.
- itch.io builds are still 32-bit and are not supported.
- Extract it into your Among Us folder first. If you used an older 32-bit (x86) BepInEx before the Steam update, replace it with this build.

If the Steam version does not start or cannot connect to Steam correctly, make sure Steam is open. Also check that your Among Us folder contains a file named `steam_appid.txt` with this content:

```text
945360
```

::note
If the modded game closes right after it starts while the unmodded game works, open `BepInEx/ErrorLog.log`. A `System.AccessViolationException` in `IL2CPPChainloader.OnInvokeMethod` or in `Interop+WinHttp.WinHttpOpen` means the BepInEx loader crashes on your Windows build. In the Among Us folder, rename `winhttp.dll` to `version.dll`. The loader works under that name too.
::

## Install the DiscordMute plugin

1. Download the latest release from [GitHub](https://github.com/YONN2222/AmongUs-DiscordMute/releases) (`AmongUsDiscordMute-<version>.zip`) and extract it. You only need `DiscordMute.dll`. The `DiscordBot` folder is for self-hosting.
2. Open your Among Us folder.
3. Go to `BepInEx/plugins`.
4. Copy `DiscordMute.dll` into that folder.
5. Start Among Us once.
6. Close Among Us again.

After the first launch, DiscordMute creates its own config folder inside BepInEx.

Example path:

```text
C:\Steam\steamapps\common\Among Us-Modded\BepInEx\DiscordMute
```

## Plugin config

Open `config.json` in `BepInEx/DiscordMute` and set `mode` to `hosted` and put in the secret from `/setup`:

```json
{
  "mode": "hosted",
  "secret": "dmh_your-secret"
}
```

In hosted mode `ip`, `botPort` and `exe` are ignored, so you can leave them as they are. Every key is explained in [plugin configuration](/configuration/plugin-config).

::warning
If the file is broken, the plugin silently falls back to its defaults (including the secret `change-me`) and the bot rejects the connection, even if the secret is right. If something doesn't work, search `BepInEx/LogOutput.log` for `Failed to read plugin config`.
::

## First start

1. Start Among Us.
2. Create a lobby as host (online or LAN, not Freeplay). The plugin does nothing when you are not the host.
3. Join a Discord voice channel and link your account with `/link self` (see [commands](/commands/slash-commands)). Send the phrase the bot gives you in the lobby chat, and you are linked.

DiscordMute mutes the voice channel the lobby host is sitting in, so the host must be linked. If the host can't be resolved, the bot falls back to the voice channels you picked in `/setup`.

::tip
Run `/testconnection` in Discord to check that the bot can reach the plugin.
::

:::

The plugin already knows the address of the hosted bot (`gateway-mute.yonn2222.com`). You do not enter it.

## Good to know

- **Generate new secret** replaces the secret. The old one stops working and games that use it are disconnected.
- You can run several games on one server. Each game mutes the voice channel its host is in.
- If the bot cannot tell which channel the host is in, it uses the fallback voice channels from the **Voice** page of `/setup`.
- Removing the bot from the server deletes the server's secret, settings and links 7 days later. Add the bot back within 7 days and everything stays as it was. The operator can delete the data earlier on request.
- A server or host the operator has blocked cannot use the bot. The plugin log says so.

All other settings work as described in the [setup panel](/server-setup/setup-panel).

## Troubleshooting

- **Nobody gets muted:** the lobby host must be linked (`/link self`) and sit in a Discord voice channel. You must host an online or local lobby, Freeplay does nothing.
- **The secret was rejected:** the plugin `secret` must be the one `/setup` created for your server. Check that `config.json` is not broken (see above).
- **You lost the secret:** run `/setup`, open the **General** page and press **Generate new secret**, then put the new secret into the plugin `config.json`.

More answers are in the [FAQ](/faq/faq).
