---
title: Slash commands
description: Link your Discord account to your Among Us name, check the connection and open the server settings.
---

Type these commands in any channel of your Discord server.

| Command | What it does |
|---------|--------------|
| `/link self` | Starts linking. The bot gives you a one-time phrase like `link-AB12`. Send it exactly as written in the Among Us Free Chat (or Quick Chat) while a lobby is open. The phrase expires after 5 minutes. |
| `/link force user display-name` | Lets a server admin link a Discord user to an Among Us name by hand. |
| `/link reset [user]` | Unlinks your own account. Unlinking someone else needs the Manage Server permission. |
| `/testconnection` | Checks whether the bot can reach the Among Us plugin. |
| `/setup` | Opens the private settings panel for this server. Needs the Manage Server permission. See [the setup panel](/server-setup/setup-panel). |

## Change your Among Us name

If you change your Among Us name, run `/link self` again. An admin can also use `/link force`.

Links are saved in `DiscordBot/data/linking.sqlite` unless you moved the file in the bot settings.
