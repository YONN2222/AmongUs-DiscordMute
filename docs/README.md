# DiscordMute docs

Live at [docs.mute.yonn2222.com](https://docs.mute.yonn2222.com), built with [Docus](https://docus.dev). Pages are Markdown in `content/`; numeric prefixes set the navigation order.

Local development: `bun install && bun run dev` (http://localhost:3000).

Pushes to `dev` deploy automatically through Cloudflare Workers Builds.
