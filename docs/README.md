# DiscordMute documentation

The DiscordMute documentation site, built with [Docus](https://docus.dev) (Nuxt). The pages live in `content/` as Markdown; the numeric prefixes set the order in the navigation.

## Run locally

```bash
bun install
bun run dev
```

The site is served at http://localhost:3000.

## Build

```bash
bun run build
```
